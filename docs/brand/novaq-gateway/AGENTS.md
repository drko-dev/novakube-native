# Nova Gateway — reglas para cualquier agente
1. Leer README.md y tokens/brand.json ANTES de disenar UI.
2. La fuente de verdad de colores es SAAS-03: novaq_tokens.css.
3. Respetar la misma identidad en Gateway, Portal, Workspace y frontend futuros.
4. No usar paletas OpenLens DevOps, Lens ni verdes/negros inventados.
5. No cambiar estructura, navegacion, permisos o API durante cambios visuales.
6. Marca aprobada: NovaKube Core, N blanca estilizada dentro de dos marcos redondeados (verde interior, gris exterior) y fondo grafito. Consultar assets/novakube-core.svg y README; no reemplazar por una N suelta ni otra marca.
7. El nombre actual es Nova Gateway; identificadores legacy --novaq-* y carpetas no representan el nombre comercial.
8. No inventar fuentes ni recursos no encontrados.
9. Antes de merge: revisar en navegador, diff visual, pruebas y auditorias.
