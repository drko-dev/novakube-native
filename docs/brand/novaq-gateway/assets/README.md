# Activos de identidad — Nova Gateway / NovaKube Core

**Decisión confirmada 18-11-2026.** El ícono aprobado es la propuesta 01 «NovaKube Core»: una N de trazo claro dentro de dos marcos redondeados concéntricos, el interior verde tecnológico y el exterior gris, sobre fondo grafito.

- `novakube-core.svg`: reproducción vectorial creada a partir de la captura de referencia entregada por el usuario. Mantiene geometría y paleta de la propuesta; **no es el SVG original de la propuesta ni garantiza equivalencia píxel por píxel**.
- La antigua `.novaq-brand-mark` CSS del SaaS es una **implementación heredada simplificada**, no el icono completo aprobado. Migrarla exige cambio específico de UI con pruebas visuales, sin afectar temas claro/oscuro en producción.
- No se ha localizado archivo maestro original SVG/PNG ni conjunto oficial de favicons; no inventar recursos alternativos. Ningún activo Lens/OpenLens forma parte de esta marca.
- El nombre comercial es **Nova Gateway**; `novaq_tokens.css` y `--novaq-*` son referencias técnicas históricas, no el nombre del producto.
